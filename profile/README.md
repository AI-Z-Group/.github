# AI-Z GmbH

AI-Z is an AI security company based in Stuttgart, Germany. We build software that helps companies prevent unintended data loss when employees use AI.

## BRANE

BRANE is our AI interaction firewall: a control layer between a company's employees and the AI models they use. It runs on-premise, as an appliance or in the customer's own infrastructure, and checks each request that passes through it before anything leaves the company's environment.

- Detected personal data, such as names, contact details, bank details and credentials, is replaced with placeholders before a request reaches a cloud model. The mapping stays on the company's BRANE server, which puts the original values back into the answer.
- Requests that must stay inside the company are answered by models running locally.
- BRANE records who sent which kind of data to which model, and when, in a tamper-evident, append-only audit log (SHA-256 hash chain). Audit reports can be exported as CSV, JSON or PDF.
